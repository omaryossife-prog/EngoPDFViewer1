# Engo Admin Panel

أداة ديسكتوب منفصلة (PyQt6) للتحكم في حسابات مستخدمي Engo، اشتراكاتهم،
أجهزتهم، مدفوعاتهم، حدود الميزات، ونسخ البرنامج الموثوقة — عن طريق الاتصال
المباشر بقاعدة Supabase.

**مهم:** الأداة دي لجهازك الشخصي فقط، **مش جزء من برنامج Engo** ولا بتتوزع
مع المستخدمين. متوزّعش ملف `engo_admin.py` ده مع نسخة Engo النهائية.

## 1) التشغيل لأول مرة

```
pip install PyQt6
python engo_admin.py
```

## 2) إعداد الاتصال

أول ما تفتح الأداة، اضغط **"إعدادات الاتصال"** واملأ:

- **رابط مشروع Supabase:** `https://milksrcwbqmkczlhjfsi.supabase.co`
  (نفس الرابط الموجود في `.env.example` بتاع Engo)
- **service_role key:** من Supabase Dashboard → **Settings → API** →
  قسم **Project API keys** → انسخ المفتاح اللي اسمه **`service_role`**
  (مكتوب جنبه "secret"، **مش** `anon` / `publishable` اللي Engo نفسه بيستخدمه).

⚠️ **المفتاح ده كامل الصلاحيات على قاعدة بياناتك بالكامل.** متحطّوش في أي
كود بيتوزّع، ومتشاركوش مع حد، ومترفعوش على GitHub. الأداة بتحفظه محليًا على
جهازك بس (عبر إعدادات النظام، مش داخل مجلد المشروع).

## 3) التبويبات المتاحة

| التبويب | بيعمل إيه |
|---|---|
| **المستخدمون والاشتراكات** | عرض كل المستخدمين (الإيميل، الاسم، حالة الحساب، الخطة، تاريخ الانتهاء)، مع بحث. وأزرار: تعليق/تفعيل الحساب، منح/سحب Premium (مع تاريخ انتهاء اختياري أو مدى الحياة)، فتح أجهزة أو مدفوعات المستخدم المحدد. |
| **الأجهزة** | كل الأجهزة المسجّلة لكل المستخدمين، مع إلغاء/إعادة تفعيل أي جهاز يدويًا. |
| **المدفوعات** | عرض سجل `payment_transactions` (للمراجعة فقط). |
| **حدود الميزات** | كل صف = ميزة واحدة لخطة واحدة (Free أو Premium) من جدول `feature_entitlements`: تفعيل/تعطيل الميزة، الحد الرقمي (فاضي = بلا حدود)، وفترة التصفير (يومي/شهري/مدى الحياة). |
| **نسخ البرنامج الموثوقة** | إضافة والموافقة على إصدارات `app_version` في `trusted_builds` — نفس الجدول اللي `get_license_context_v1` بيتأكد منه قبل ما يدي أي صلاحيات. |

## 4) ملاحظات مهمة

- منح/سحب Premium بيتم عن طريق إلغاء أي اشتراك "نشط/تجريبي" سابق للمستخدم
  وإضافة صف اشتراك جديد — نفس المنطق اللي سيرفر Engo بيعتمد عليه، فمفيش
  تعارض.
- كل عملية (تعليق حساب، منح/سحب اشتراك) بتتسجّل تلقائيًا في `license_events`
  كسجل تدقيق (`admin_panel` في حقل `details.actor`).
- إعادة تفعيل جهاز ملغى ممكن تفشل لو المستخدم عنده جهاز نشط تاني بالفعل
  (القيد `devices_one_active_per_user` بيسمح بجهاز نشط واحد بس لكل مستخدم) —
  هتظهرلك رسالة الخطأ من السيرفر في الحالة دي.
